detour into language design.

## What a post looks like

Posts are plain Markdown with a small front-matter block. Code gets syntax
highlighting at build time:

```cpp
// A fusion decision, roughly.
bool ShouldFuse(const HloInstruction* producer, const HloInstruction* consumer) {
  if (producer->opcode() == HloOpcode::kBroadcast) return true;
  return !IsExpensive(*producer) || producer->user_count() == 1;
}
```

```mlir
func.func @matmul(%a: tensor<128x256xf32>, %b: tensor<256x64xf32>) -> tensor<128x64xf32> {
  %0 = tensor.empty() : tensor<128x64xf32>
  %1 = linalg.matmul ins(%a, %b : tensor<128x256xf32>, tensor<256x64xf32>)
                     outs(%0 : tensor<128x64xf32>) -> tensor<128x64xf32>
  return %1 : tensor<128x64xf32>
}
```

## Math

Set `math: true` in the front matter and use `$...$` or `$$...$$`. Arithmetic
intensity of a matmul: $I = \frac{2MNK}{2(MK + KN + MN)}$ flop/byte, so for a
square $N \times N$ product

$$ I = \frac{2N^3}{6N^2} = \frac{N}{3}. $$
